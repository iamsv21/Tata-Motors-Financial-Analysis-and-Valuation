# Tata-Motors-Financial-Analysis-and-Valuation
🔍 Project Overview
Company Analyzed: Tata Motors Ltd.

Tools Used: Microsoft Excel

Objective: To evaluate the financial health and intrinsic value of Tata Motors using DCF and key financial metrics.

📈 Key Features
Performed historical financial analysis (3–5 years) including vertical, horizontal, and ratio analysis.

Built a DCF model incorporating:

Revenue, EBITDA, and Net Profit forecasting

Free Cash Flow to Firm (FCFF) estimation

Weighted Average Cost of Capital (WACC) calculation

Terminal value and sensitivity analysis

🎯 Purpose
This project is for educational purpose and demonstrates skills in financial modeling, valuation, forecasting, and Excel automation relevant for roles such as Financial Analyst, Equity Research Analyst, and Investment Analyst.
